Từ Điển Mã Lỗi (Error Codes)

Các mã lỗi thường gặp khi làm việc với Google Gemini API

400

Bad Request (Yêu cầu không hợp lệ)

Dữ liệu gửi đi bị lỗi format hoặc Prompt quá dài, chứa nội dung bị cấm.

💡 Khắc phục: Kiểm tra lại nội dung Prompt (Idea). Xóa bớt các ký tự đặc biệt lạ. Giảm bớt số lượng ảnh upload nếu quá nặng.
401

Unauthenticated (Lỗi xác thực)

API Key bị sai, đã bị xóa, hoặc chưa được kích hoạt tính năng thanh toán (với model Pro).

💡 Khắc phục: Vào tab Quản lý API Key, xóa Key cũ và thêm Key mới chính xác từ Google AI Studio.
403

Permission Denied (Từ chối truy cập)

Thường gặp khi truy cập Model không khả dụng tại quốc gia (Region lock) hoặc tài khoản bị Google khóa.

💡 Khắc phục: Đổi sang Model Gemini 2.5 Flash hoặc dùng VPN đổi IP sang Mỹ/Singapore.
404

Not Found (Không tìm thấy Model)

Tên Model trong cấu hình không tồn tại hoặc đã bị Google ngừng hỗ trợ.

💡 Khắc phục: Chọn lại Model trong danh sách (Ví dụ: Gemini 2.5 Flash Lite) thay vì dùng Model cũ.
429

Resource Exhausted (Hết lượt / Quota)

Đây là lỗi phổ biến nhất. Bạn đã dùng hết số lượng request miễn phí trong phút/ngày.

💡 Khắc phục:
  • Chờ khoảng 1-2 phút rồi thử lại.
  • Tạo thêm nhiều API Key khác (từ các tài khoản Google khác nhau) và thêm vào phần mềm để luân phiên sử dụng.
5xx

Server Errors (500, 502, 503)

Lỗi từ phía máy chủ Google (quá tải, bảo trì).

💡 Khắc phục: Không thể can thiệp. Vui lòng chờ vài phút và nhấn thử lại.

✨ Tab Generator (Kịch Bản)

1. Quy tắc Path Ảnh (Quan trọng)

Phần mềm lưu đường dẫn tuyệt đối (Full Path) của ảnh vào Excel chứ không copy ảnh vào phần mềm.

⚠️ Cảnh báo: Sau khi xuất Excel, tuyệt đối không được đổi tên, di chuyển hoặc xóa file ảnh gốc trên máy tính. Nếu không ToolFlows sẽ báo lỗi không tìm thấy ảnh.

2. Chế độ Text vs I2V

  • TEXT Mode: Nếu không upload ảnh nào, AI sẽ tự sáng tạo hình ảnh mô tả.
  • I2V Mode: Chỉ cần upload 1 ảnh, AI sẽ tự động chuyển sang chế độ Image-to-Video, sử dụng ảnh đó làm tham chiếu (Reference) cho tất cả các cảnh.

🔑 Quản lý API Key

Hệ thống hỗ trợ lưu nhiều Key cùng lúc. Bạn nên chuẩn bị ít nhất 3 Key để tránh bị gián đoạn do lỗi 429 (Hết lượt).

  • Nhấn nút trên Header để vào quản lý.
  • Nút xanh ✓: Chọn Key đang hoạt động.
  • Nút đỏ 🗑: Xóa Key hỏng.

🎬 Tab Tracker (Xưởng Phim)

A Cơ chế Auto-Reload

Phần mềm có một bộ đếm chạy ngầm mỗi 2 giây. Nó sẽ quét thư mục chứa file Excel để tìm các file video `.mp4` mới được tạo ra.

* Điều kiện nhận diện: File video phải có tên chứa mã Job (VD: `Job_1.mp4`, `MyProject_Job_1.mp4`).

B Kết nối ToolFlows

1. Nhấn icon ⚙️ (Cài đặt) cạnh nút "MỞ TOOLFLOWS".

2. Trỏ đường dẫn đến file ToolFlows.exe (hoặc tool tạo video bất kỳ).

3. Sau đó nhấn nút "MỞ TOOLFLOWS" để khởi chạy tool ngay từ phần mềm.

C Ghép Phim (FFmpeg)

1. Ghép Thường Nối đuôi tất cả video đã hoàn thành thành 1 file dài. Giữ nguyên độ dài gốc của từng clip.
2. Ghép Theo Nhạc (Timed) Tự động cắt ngắn video output sao cho tổng thời lượng khớp chính xác với số phút/giây bạn đã nhập ở tab Generator.
3. Ghép Tất Cả (Combine All) Duyệt qua danh sách các file Excel đang theo dõi. Nếu file nào có video hoàn thành, nó sẽ tự động ghép và xuất ra thư mục bạn chọn.
